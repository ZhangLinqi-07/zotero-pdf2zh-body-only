Kinbo 0.4.2 配套 Zotero 插件 4.1.7.14，修复 Codex 登录方式兼容性并改善 macOS 程序查找与错误诊断。

登录按钮优先使用官方浏览器登录，确认无法使用时才尝试设备码。支持官方 chatgpt.com 登录域名，避免固定设备码流程受账号设置影响。协议错误显示失败步骤、错误码及可识别的 CLI 版本，不返回原始错误、密钥或登录令牌。新增常见 Mac Homebrew 路径查找，并将 macOS 纳入自动测试。具体设备的登录问题仍需通过新版提示与复测确认。

在 Zotero 插件管理器点击 Check for Updates 即可检查并安装正式发布的 XPI。XPI 携带对应后台源码更新包，已安装 0.4.1 或更新后台的用户，会在本机翻译、阅读和对话任务完成后自动同步。更新保留 API 配置、论文、译文、笔记和虚拟环境，启动失败时恢复旧版源码。

使用 0.3.x 或 0.4.0pre1 后台的用户需要先手动升级一次后台，以安装安全更新接口。可下载本次 ZIP，在停止旧服务后对原后台目录运行 install.py；全新安装仍使用 install-windows.cmd。首次迁移后，同一依赖范围内的后续更新可通过 Zotero 完成。依赖版本发生变化时会提示使用完整安装器。

只有发布带版本号的 Release 并上传校验通过的安装包后，更新通道才会切换。普通源码推送不会触发用户升级。具体安装和模型配置见仓库 README。
