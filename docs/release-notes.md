Kinbo 0.4.3 配套 Zotero 插件 4.1.7.15，增加 Windows 登录后静默启动后台，并修复重复启动时的文件锁错误。

Windows 本机后台首次启动或更新重启时，会为当前用户注册登录启动任务，沿用实际安装目录、Python 环境和端口。以后登录 Windows 不用手动开终端。任务支持电池供电和长时间运行，重复启动不会产生第二个服务；由任务启动的进程异常退出后每分钟重试，最多三次。注册失败会在后台日志和能力查询中明确提示。此功能不改变 macOS、Linux 和远程后台的启动方式。

在 Zotero 插件管理器点击 Check for Updates 即可检查并安装正式发布的 XPI。XPI 携带对应后台源码更新包，已安装 0.4.1 或更新后台且正在运行的用户，会在本机翻译、阅读和对话任务完成后自动同步，并在新版重启时配置登录启动。旧后台如果已经关闭，首次升级仍须先手动启动一次。更新保留 API 配置、论文、译文、笔记和虚拟环境，启动失败时恢复旧版源码。

使用 0.3.x 或 0.4.0pre1 后台的用户需要先手动升级一次后台，以安装安全更新接口。可下载本次 ZIP，在停止旧服务后对原后台目录运行 install.py；全新安装仍使用 install-windows.cmd。首次迁移后，同一依赖范围内的后续更新可通过 Zotero 完成。依赖版本发生变化时会提示使用完整安装器。

只有发布带版本号的 Release 并上传校验通过的安装包后，更新通道才会切换。普通源码推送不会触发用户升级。具体安装和模型配置见仓库 README。
