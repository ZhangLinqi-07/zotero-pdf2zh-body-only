# Kinbo 0.4.4

Kinbo 是在 Zotero 中使用的 PDF 翻译、论文深度阅读与 AI 论文对话工具。本版正式发布新的阅读器对话界面，配套 Zotero 插件版本为 **4.1.7.16**。

## 本次更新

- **证据伴读侧栏**：默认 336px，支持浅色、深色与窄窗口；选文提问、页码引用、唯一原句临时高亮、历史消息与模型设置保留在阅读流程中。
- **清晰的操作状态**：空状态、生成中、停止、失败恢复与面板内清空确认；重新连接保留已有回答，不自动发起模型生成。
- **精简右键菜单**：增强区只保留一个随当前论文任务切换的「深度阅读 / 停止阅读」入口，并配小图标。论文对话、模型登录和后台更新管理位于 Zotero 工具菜单。
- **Kinbo 产品身份**：插件管理器采用 Kinbo 名称与图标；README 围绕产品功能、安装、更新与科研工作流重写。
- **生命周期修复**：关闭窗口、停用与卸载时清理侧栏、工具栏、事件与计时器；处理已关闭 Reader 的失效 DOM 引用。

## 已有用户更新

在 Zotero「工具 → 插件 → 齿轮 → 检查更新」中安装新版。插件 ID、设置键和更新地址保持兼容，无需卸载旧插件或重新填写 API。

XPI 携带 Kinbo 0.4.4 后台源码包。0.4.1 及更新后台需正在运行，插件会等待翻译、深度阅读与对话任务空闲后同步；保留配置、论文、译文、阅读历史、笔记和 Python 环境，启动检查失败时回滚。旧后台首次迁移尚未配置自启动时，请先手动启动原后台。远程后台、修改过的受管理源码或依赖不匹配时会提示人工处理。

0.3.x 与 0.4.0pre1 后台需要先用本版 ZIP 对原服务目录执行一次 install.py，以装入更新接口；全新 Windows 安装使用 install-windows.cmd。安装步骤见 README。

## 保留的工作流

后台 Web 控制页、翻译引擎、完整 PDF / 全部页面阅读、Codex 登录、共享 API、论文会话、原文定位和笔记归档沿用现有流程。本版没有迁移生产数据格式，也没有重写上游翻译设置页面。

本轮自动验证使用合成内容和模拟模型接口；Zotero 原生安装与 Reader 验证使用独立资料库，不将其视为真实模型生成质量测试。版本、包内资源和下载校验值随本次发布一并核对。
