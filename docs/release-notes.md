# Kinbo 0.4.6

修复 Mac 只安装 Codex 桌面版时提示“未找到 Codex CLI”的检测兼容问题。配套 Zotero 插件为 **4.1.7.18**。

## 本次更新

- 自动识别系统或用户“应用程序”文件夹中 Codex.app 自带的程序，无需为了 Kinbo 另装 CLI。已有 CLI 和显式配置的路径继续优先。
- 没有检测到可用程序时，在登录区域显示安装与刷新指引。
- Codex 登录错误显示在登录控件旁；使用现有翻译 API 的阅读不受 Codex 缺失影响。

## 已有用户更新

在 Zotero「工具 → 插件 → 齿轮 → 检查更新」中安装新版，然后完全退出并重开 Zotero。也可下载本页 XPI 覆盖安装。

Mac 请将 Codex.app 放在系统或用户“应用程序”文件夹中，更新后在 Kinbo 模型控制页点“刷新登录与模型”；如提示未登录，再完成官方登录。使用现有翻译 API 无需安装或登录 Codex。

0.4.1 及更新后台可通过 XPI 中的 0.4.6 源码包自动同步，等待翻译、阅读及对话空闲后更新，启动检查失败回滚。0.3.x / 0.4.0pre1 仍需先按 README 完成一次迁移。新用户使用完整 ZIP 中对应系统的安装器。

## 验证范围

覆盖桌面版路径、执行权限、缺少程序时的 API 阅读和登录失败提示；自动验证使用合成内容与模拟接口，不调用收费模型。已核对桌面及手机宽度的网页显示。Mac 桌面版的实际登录与阅读仍需用户设备复测，跨平台测试不等同于该设备验收。
