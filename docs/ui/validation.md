## 真实 Zotero

在 Zotero 10.0.7 中通过常规 XPI 安装，用新的隔离 profile、独立资料库、两页合成 PDF、模拟 HTTP 接口验证：

- 全部页面文本、原句唯一匹配及 41 个字符矩形；
- 侧栏 336px、浅深色的实际 computed style、左右切换、选文展示与发送、停止生成、模型列表；
- 物理页码引用、原生点击、高亮显示及关闭清理；
- 已有历史与重新打开、主窗口/独立 Reader 窗口切换；
- 单一菜单启动模拟深度阅读、切换到停止并取消、管理入口迁到 Tools 和 SVG 资源；
- 插件停用后侧栏、工具栏和 Tools 菜单移除，卸载完成。

迭代过程保留了失败证据：一次截图路径混用斜杠失败；两次隔离 profile 的初始文库加载与创建合成条目竞争，卡在 Reader.open；等待初始 item 数据完成后已解决。窗口测试还找出了 Gecko dead wrapper 中断插件清理的问题，已在 Reader 适配层处理并新增回归。

真实输入控件的背景分别核对为 `rgb(255,255,255)` 与 `rgb(38,42,47)`，深色图标为 `rgb(229,233,237)`。Zotero chrome 对表单的覆盖通过 `no-native` 外观退出属性处理。隐藏测试窗口不会稳定推进合成器过渡，最初的图标颜色断言因此失败；原生截图测试将反馈时长设为 0ms 后验证稳定状态，不修改生产动画或用户偏好。

本地验证包 SHA-256：`66fefed0255e02ebf67525b42ea1b4e3f675c1d05c8b9bb22f31e12236e9b57f`。ID、版本与自动更新地址沿用当前值，本地包仅供审阅，不作为正式发布物。

## 0.4.5 升级与自动启动补充

上文保留初始 UI 阶段及 0.4.4 发布的历史边界。0.4.5 针对实际反馈增加了覆盖升级清理和后台自动恢复，不改变后台 Web 页、API 路由 / 协议、插件 ID 或生产数据格式。

旧代码在包含双根菜单与旧阅读入口的回归夹具中稳定失败（两个根菜单）；修复后保留当前上游命令且只有一个阅读入口。另覆盖清理函数抛错、停用后初始化返回、目录关联、原端口 / 虚拟环境保留、用户取消、远程服务不自动启动及停用后等待计时器解除。Reader 重连先经过后台恢复，不会在服务未就绪时创建会话。

本地完整 Python 检查共 185 项：173 项通过，12 项跳过（11 项需要翻译引擎，1 项需要 POSIX 符号链接权限）；六组 JavaScript 检查通过。后台更新集成检查使用真实服务执行等待空闲、重启和配置 / 笔记保留，版本 0.4.5。

Windows Zotero 10.0.7 隔离环境中，从 4.1.7.15 打开并关闭 Reader 后覆盖安装 4.1.7.17，验证单菜单、浅深色、选文提问、历史、页码 / 高亮、取消、独立 Reader 切换、停用与卸载。测试使用两页合成 PDF、模拟模型接口，未使用日常资料库或收费模型。

macOS 的 LaunchAgent 和全新后台安装加入 macOS CI：前者用临时标准库服务验证实际 launchd 与重复唤醒不重启，后者校验 uv 下载并用独立 Python 环境安装实际后台，翻译引擎延后安装；均清理临时服务。CI 缺少 GUI 登录域时明确记录 skipped，不算实机通过。Mac 原生 Zotero 界面仍需用户设备复测。
